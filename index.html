ZEROPROXY 隐私政策

最后更新日期：2025年8月28日

重要提示： 本扩展是一个在您本地设备上运行的客户端工具。我们不运营任何中央服务器，也不会收集、存储或传输您的个人身份信息或浏览数据。

1. 信息收集与使用

本扩展仅出于核心功能所需，在您的浏览器本地处理极其有限的信息。我们不会将任何此类信息发送到我们自己的服务器。

Proxy 权限

用途： 此权限对于实现本扩展的核心代理功能（包括直连模式、全局代理模式和自动代理模式）是必需的。

数据处理： 此权限允许本扩展根据您的设置重定向您的网络流量。所有流量重定向操作仅在您的本地设备上完成。我们不会记录、监控、存储或传输您的任何网络流量内容（如您访问的网址、搜索查询、输入的表单数据等）。

Storage 权限

用途： 此权限用于保存和调用您在本扩展中进行的个人配置和设置。

数据处理： 您的所有配置（例如，您选择的代理模式、自定义规则等）都仅存储在您本地设备的浏览器存储区域中。这些数据永远不会被自动同步或传输给我们或任何第三方（除非您使用了浏览器的同步功能，如Chrome Sync，则该过程受Google隐私政策的约束）。

Host Permissions (例如：https://raw.githubusercontent.com/*)

用途： 此权限仅用于从您指定的公开GitHub仓库（或其他您配置的规则源）获取和更新中国域名白名单规则列表。

数据处理： 本扩展会访问上述公共URL以拉取规则文件。这个过程不涉及传输您的任何个人数据或浏览历史。我们拉取的是公开的、非个人的域名列表。您的浏览器可能会在此过程中将您的IP地址发送给GitHub（作为任何常规网页请求的一部分），此行为受GitHub隐私政策的约束。

2. 数据共享与披露

我们不会出售、交易或以其他方式将您的任何信息转让给外部第三方。由于我们首先就不收集任何个人数据，因此没有任何数据可供共享或披露。

3. 数据安全

我们采用行业标准实践来保护您存储在本地的配置信息，但由于所有数据都存储在您的本地设备上，您设备的安全性对于防止未经授权的访问也至关重要。

4. 您的权利

由于您的所有数据都存储在本地，您拥有对其的完全控制权。您可以随时通过本扩展的选项页面查看、修改或清除您的所有配置数据。

5. 隐私政策的变更

我们可能会不时更新本隐私政策。任何更改都会在本页面发布更新后的隐私政策，并更新顶部的"最后更新日期"。建议您定期查看本政策以了解任何变更。
